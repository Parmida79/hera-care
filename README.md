# 🧬🩺 PCOS Diagnosis & Personalized Care Assistant
An end-to-end MLOps pipeline for early PCOS detection and personalized lifestyle recommendations using streaming data, XGBoost, and explainable AI (SHAP).

🛠 **Features**
- Real-time patient data ingestion (Kafka)
- Orchestration with Apache Airflow
- XGBoost model with 95%+ accuracy
- SHAP explanations (medical-grade interpretability)
- Personalized diet & exercise plans
- FastAPI + Streamlit demo
